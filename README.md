# The Meeting That Should Have Been One Line

One sentence that could have replaced an entire pointless meeting:
the email it should have been, and the empty ritual that took its place.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` validates the line (single line, 1–199 characters, not blank)
and writes it plus a trailing newline to `/output/entry.txt`.
